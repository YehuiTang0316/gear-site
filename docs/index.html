A few things to know.

Does GEAR replace my agent?+

GEAR works with your agent environment through its Refine Skill. Use Codex, Claude Code, DSH, or another compatible environment. The Meta agent that proposes changes can use a different model from the task agent.

Can I use my own tasks?+

Yes. Define representative tasks and clear success criteria in Harbor format. You control the benchmark, optimization objective, evaluation budget, and the components GEAR may change.

Can it train the model too?+

Harness optimization is supported today. Model training is experimental; the complete joint model-and-harness optimization loop and automatic seed-task generation remain under development.
