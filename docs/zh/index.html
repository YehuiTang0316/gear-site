你可能还想了解。

GEAR 会替代我现在的 Agent 吗？+

GEAR 通过 Refine Skill 与你的 Agent 环境协作。你可以使用 Codex、Claude Code、DSH 或其他兼容环境。提出改进的 Meta agent 与执行任务的 Agent 可以使用不同的模型。

可以使用自己的任务集吗？+

可以。通过 Harbor 格式定义有代表性的任务和明确的验收标准。Benchmark、优化目标、评测预算，以及 GEAR 可以修改的组件，都由你掌控。

它也可以训练模型吗？+

目前已支持 harness 优化。模型训练仍处于实验阶段，完整的模型与 harness 联合优化闭环，以及自动 seed task 生成仍在开发中。
